## v1.1.0 - 2026-11-23

### Added

- Administration › Backup and restore shows each snapshot's schema version beside this version's, says when a snapshot is too new to restore, and can delete a snapshot. The API adds DELETE /api/snapshots/{name}, for instance administrators.
- A picture chosen for a person or a team opens a crop dialog: drag to place it, zoom with the slider or the wheel, then Use this. Before, it was always cropped from the centre.

### Changed

- The sidebar has one Team entry; team settings open from the team's page. The sidebar follows the team of the ticket or bucket open, and a fresh load starts on the team last used.
- Administration, team settings, team and personal profiles and Account use up to 1200px of a wide window, with the person or team, or the account's password and 2FA, in a side column.
- Administration has five sections instead of seven: Instance (version, updates, data directory and a status list), People (users and teams), Appearance, Backup and restore, and Integrations. An empty snapshot list says so, and the icon set upload uses Campfire's own file button.
- The bucket index, the Bucket field and the search suggestions leave out rejected buckets and buckets done for more than three days, as the board does with done tickets. Show finished on the bucket index brings them back. The list_buckets MCP tool still returns every bucket.
- A ticket's State field no longer repeats the state's role, and an empty Bucket field reads No bucket. Account is titled Account and says when it has no agent tokens.

### Fixed

- Administration writes snapshot, restore and update-check times like the rest of the app (5 Nov 2026, 12:21) instead of in the browser's locale, which in some wrote them with dots.
